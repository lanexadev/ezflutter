# Changelog

All notable changes are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [3.0.0] - 2026-08-07

### Added

- Deterministic `startdart` CLI for creating applications and scaffolding features and models.
- `start_dart` Flutter package with typed results, failures, validation, async state, pagination, and retry primitives.
- Feature-first MVVM starter with development, staging, and production environments.
- Universal `AGENTS.md` contract with provider-neutral rules, skills, hooks, references, and vendor adapters.
- Repository governance, security reporting, contributor templates, and Android/iOS release checks.

### Changed

- Renamed the project from EzFlutter to START.DART.
- Rebuilt the project as an AI-native application system rather than an in-place framework upgrade.
- Limited generated targets to Android and iOS.

### Removed

- Generated-code-heavy V2 architecture and unsupported legacy APIs.

## [2.0.0] - 2026-04-02

- Final EzFlutter V2 release. This version is no longer supported.
