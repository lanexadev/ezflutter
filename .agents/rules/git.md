# Git rules

- Work on the requested branch and preserve unrelated user changes.
- Keep commits focused and use Conventional Commit subjects: `type(scope): imperative summary`.
- Do not rewrite shared history, force-push, or delete branches without explicit authorization.
- Never add AI attribution, AI co-authors, or generated-by trailers.
- Do not bypass hooks or checks to make a change appear green.
- Review the final diff for secrets, generated noise, and unintended platform files before committing.
- Release tags use `v<major>.<minor>.<patch>` and must correspond to the documented package versions.
