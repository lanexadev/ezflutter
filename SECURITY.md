# Security policy

## Supported versions

Security fixes target the latest V3 release. EzFlutter V2 is unsupported.

## Reporting

Do not disclose a vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository. Include affected versions, impact, reproduction steps, and any suggested mitigation.

Do not include real secrets or personal data in a report. We will acknowledge a valid report, coordinate remediation, and credit reporters who want attribution.
